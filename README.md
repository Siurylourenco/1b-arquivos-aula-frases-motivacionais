# 💡 Projeto: Gerador de Frases Motivacionais

Este é um projeto simples de página web que exibe frases motivacionais aleatórias ao usuário. O projeto foi desenvolvido com foco na prática de **HTML5**, **CSS com Bootstrap** e **JavaScript puro**, e tem como objetivo reforçar conceitos básicos de interação dinâmica com o DOM e manipulação de arrays em JavaScript.

## 🖥️ Funcionalidades

- Exibição de uma frase motivacional aleatória ao carregar a página.
- Botão para gerar novas frases de forma dinâmica.
- Interface responsiva utilizando o framework **Bootstrap 4.5.2**.

## 🚀 Tecnologias Utilizadas

### 🔹 HTML5
- Estrutura da página.
- Organização semântica dos elementos.

### 🔹 CSS com Bootstrap
- Estilização da interface usando o framework Bootstrap.
- Uso da classe `jumbotron`, `container`, `btn`, entre outras, para tornar a página mais agradável visualmente e responsiva.

### 🔹 JavaScript
- Manipulação do DOM com `document.getElementById`.
- Criação de uma função chamada `gerarFraseMotivacional()` que:
  - Armazena uma lista (array) com 10 frases motivacionais.
  - Gera um número aleatório com `Math.random()` e `Math.floor()`.
  - Seleciona uma frase com base nesse número.
  - Substitui o conteúdo do elemento HTML com ID `frase` pela nova frase.

## 📚 Conteúdos Estudados e Praticados

Este projeto foi utilizado como forma de reforçar os seguintes conceitos:

- Manipulação de arrays em JavaScript.
- Geração de números aleatórios.
- Interação com o DOM (Document Object Model).
- Boas práticas na estruturação de código HTML.
- Utilização de componentes prontos do Bootstrap para criar interfaces rapidamente.
